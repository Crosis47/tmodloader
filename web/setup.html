Create your admin token

The game is paused until you finish setup. Find the one-time setup code in your container logs using docker compose logs tmodloader.

Choose a unique token of 8–256 ASCII characters without spaces. Save it in your password manager. Only its Argon2id hash will be stored on the server.

Use HTTPS for remote access, or a localhost SSH tunnel. The setup code expires when setup finishes or the container restarts.
