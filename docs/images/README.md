# Dashboard screenshots

The four `dashboard-*.png` README images were captured on 2026-09-17 from the
unmodified `web/index.html`, `web/app.js`, and `web/style.css` in container source
version 3.2.0 (documentation checkout `913cf7c`). They are browser screenshots,
not drawn mockups. Each capture uses a 1440-pixel-wide viewport and the full page.

Server status, players, world files, backups, selections, and search responses
use demonstration data supplied to the current interface. These captures do not
claim a live game-server test or authenticated Steam search. No credentials or
private server data are present.

Workshop titles, descriptions, update dates, subscriber counts, and artwork came
from Steam's public item-details endpoint for Calamity Mod (`2824688072`), Magic
Storage (`2563309347`), and Recipe Browser (`2619954303`). The browser loaded the
original Steam preview images. The three-item results list is illustrative;
descriptions are shortened for the gallery. Artwork belongs to its respective
creators.

- `dashboard-overview.png`: health, players, settings, and backup status.
- `dashboard-worlds.png`: expanded world metadata and uptime, with Journey controls.
- `dashboard-backups.png`: expanded archive contents and compatibility.
- `dashboard-workshop.png`: Steam search controls and graphical Workshop mod cards.

When refreshing these captures, use the current UI, keep the gallery's data-source
caption accurate, and check that all artwork has loaded before capturing.
